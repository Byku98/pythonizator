# Code Review — ocena kodu AI

Ten modul uczy oceniac kod generowany przez AI. To jest Twoj glowny skill w 2026.

## Co tu znajdziesz

- `checklist.md` — co sprawdzac przy review
- `antipatterns.md` — typowe bledy AI
- `security.md` — dziury w kodzie AI
- `examples/` — przyklady kodu do review

## Jak uzywac

1. Zacznij od `checklist.md`
2. Probuj ocenic kod z `examples/`
3. Uzywaj agenta `career` do review — "co bys zmienil?"

## Dlaczego to wazne

Nie musisz pisac kodu od zera. Musisz rozumiec co robi i czy jest dobrze. To jest realna umiejetnosc w firmie.
