# Interview Prep — co zapytaja na rozmowie

Ten modul przygotowuje do rozmowy kwalifikacyjnej na Python Developera (mid level).

## Co tu znajdziesz

- `python-questions.md` — typowe pytania techniczne
- `fastapi-questions.md` — pytania o FastAPI
- `system-design.md` — jak projektowac API
- `behavioral.md` — co powiedziec o swoim doswiadczeniu
- `mock-interviews.md` — symulacje rozmow

## Jak uzywac

1. Zacznij od Modulu 1-3 (foundations, FastAPI, testy)
2. Potem wracaj tu i cwicz
3. Uzywaj agenta `career` do mock interviews

## Wazne

Twoja karta przetargowa to 10 lat w IT. Nie ukrywaj tego — wykorzystaj. Rozumiesz architektur systemow, zaleznosci, pipeline'y. To sie liczy.
