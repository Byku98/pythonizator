# Pythonizator — nauka Pythona od zera

Sandbox do nauki programowania w Pythonie. Portfolio bedzie w osobnych repozytoriach.

## Struktura

```
exercises/
├── month01/          # Fundamenty Pythona (sprint)
├── month02_oop/      # OOP + zaawansowany Python
├── month03_async/    # Async i wzorce projektowe
├── month04_fastapi/  # FastAPI + bazy danych
├── month05_architecture/ # Clean Architecture, DDD
├── month06_devops/   # DevOps i platform engineering (mies. 6-7)
├── month08_ai/       # AI i LLM
└── month09_go/       # Go + portfolio
```

## Jak uzywac

1. Otworz ten projekt w opencode
2. Uzyj agenta `career` (domyslny agent w tym projekcie)
3. Zaczynaj od Miesiaca 1
