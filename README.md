# Pythonizator — nauka Pythona dla ludzi z IT

Sandbox do nauki Pythona dla osoby z doswiadczeniem w IT (integracja, K8s, DB, Linux). Nie uczymy sie od zera — przyspieszamy.

## Cel

Zmienic prace z integratora na Python Developera (mid) w ciagu ~1 roku. Kluczowe umiejetnosci:
- Czytac i rozumiec kod Python
- Ocenic kod generowany przez AI
- Przejsc rozmowe kwalifikacyjna
- Dociagnac swoj projekt (Wireshark dla GenZ)

## Struktura

```
exercises/
├── foundations/        # Python dla ludzi z Javy
├── interview-prep/    # Co zapytaja na rozmowie
├── code-review/       # Ocena kodu AI
└── project/           # Wireshark dla GenZ
```

## Jak uzywac

1. Otworz ten projekt w opencode
2. Uzyj agenta `career` (domyslny agent w tym projekcie)
3. Zaczynaj od Modulu 1 (Python vs Java)

## Profil

- **Doswiadczenie:** 10+ lat w IT (integracja, firewalle, K8s, DB, Linux, Windows, AD)
- **Java:** Spring, Hibernate, modyfikatory (private/public)
- **Frontend:** Podstawy React (ale to nie jest cel)
- **AI:** Uzywa AI do pisania kodu, chce rozumiec co generuje
- **Czas:** 2-3h tygodniowo
